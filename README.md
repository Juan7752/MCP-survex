# MCP-survex: Matienzo Caves Project (MCP) Survex survey data

Survey data for the caves around Matienzo, Cantabria, from the Matienzo Caves Project.
Cave folders inside s/ are named by cave code (e.g. s/0733 = Cueva Vallina).

To contribute, see the contributor guide: [link to guide]
Only .svx files are stored here; process with Survex (https://survex.com) to get .3d files.
Please do not submit .3d, .err, .pos or .log files.
